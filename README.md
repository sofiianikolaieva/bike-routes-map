# Карта веломаршрутів міста

Навчальний веб-застосунок (Програмування веб-застосувань, ФІОТ КПІ, варіант 14).
Виконала: Ніколаєва С.О., група ІП-51.

## Запуск

```bash
cd server
npm install
npm start
```

Відкрити в браузері: http://localhost:3000

## Безпека (ПР 15)

### XSS через innerHTML

| Місце | Що виявлено | Як виправлено |
|---|---|---|
| `showAddedNotice()` — повідомлення «Маршрут … додано» | Назва маршруту з форми вставлялась через `innerHTML`. Назва `<img src=x onerror="alert('XSS')">` виконувала скрипт. | Розмітка створюється через `createElement`, назва — через `textContent`. Тестовий рядок тепер показується як текст. |
| `showPageBlocks()`, `renderRouteDetailsList()` | `innerHTML = ''` лише для очищення — безпечно. | Замінено на `replaceChildren()`. |
| Картки маршрутів (Vue, `RouteCard`) | `{{ name }}` автоматично екранує HTML, `v-html` не використовується. | Змін не потрібно. |
| Деталі маршруту, «Не знайдено», помилки, Canvas | Вивід через `textContent` і `fillText()`. | Змін не потрібно. |

### localStorage / IndexedDB

- **IndexedDB** `BikeRoutesDB` → `routes`: id, name, distanceKm, difficulty, city — публічні дані про маршрути, без персональної інформації.
- **localStorage**: лише службовий прапорець `routesMigrated`.
- Паролі, токени та персональні дані користувача не зберігаються.

### Секрети в коді

API-ключів, токенів і паролів у коді немає. Зовнішня адреса — лише публічний CDN бібліотеки Vue.

### HTTPS

Для фінальної здачі застосунок планується розгорнути на **Render** (безкоштовний хостинг для Node.js із HTTPS за замовчуванням), бо він має сервер Express з API `/api/routes`. Статичний хостинг на кшталт GitHub Pages не запускає Node.js, тому API там не працюватиме. Сервер бере порт зі змінної середовища `PORT`, як вимагає хостинг.
